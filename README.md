## My Magic the Gathering Binder

This is a passion project that I started to create a portfolio for my Magic: the Gathering card collection. I wanted to learn how to build a web application using NextJS and also how to use the Scryfall API for future projects. The design is still a work in progress but most of the functionality is there.

### Features
- You can search for a card that you want to add to your binder
- You can track the card price as well as remove any cards from the binder.
